iPhone 测试步骤
  1. 打开 Wi-Fi 和蓝牙，亮屏触碰 NFC，然后打开照片；无需 NFC Tools。
  2. 先用一张小照片或截图：照片 → 分享 → 隔空投送 → Photo Frame。
  3. 如果设备不出现，保持分享页面打开，观察下方 AWDL、发现和 TLS 状态。
  4. 原图完整校验并保存后显示；C5 分块接收的解包文件包上限为 128 MiB。
